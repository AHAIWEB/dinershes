# Dinershes_দিনের শেষ 

সংক্ষিপ্ত নির্দেশনা আমাদের reference newspaper design অনুসরণ করে একটি professional ৪ পৃষ্ঠার বাংলা e-paper system তৈরি করতে হবে। এতে public e-paper website এবং admin panel থাকবে। Admin panel থেকে প্রতিটি page-এর column, article, image, headline, image size, image style, spacing, advertisement এবং section পরিবর্তন করা যাবে। Drag-and-drop page builder, article management, media library, user role, draft, review, preview, scheduled publish, PDF export, print এবং mobile responsive layout থাকতে হবে। প্রথমে UI/UX design ও working prototype দেখাতে হবে। Design approval-এর পর development শুরু করতে হবে। Final delivery-তে source code, admin access, hosting deployment, documentation, training এবং bug-fixing support দিতে হবে।  👉দিনের শেষ খবর নামে ইপেপার।  সারাদিনের টপ খবর নিয়ে প্রথম আলো/যুগান্তর ইত্যাদি ইপেপার এরমতো পাবলিশ করে সোশাল মিডিয়ায় প্রিন্ট নিউজের সাধে গ্রহন যোগ্য।
